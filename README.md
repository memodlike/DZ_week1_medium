## Логика решения

- **Вводные из задания:** 12 месяцев истории, 600 заказов в день, снижение повторных покупок за последние 2 месяца, стабильное привлечение, текущий retention 15%, цель 30–35%.
- **15% → 30–35%** — рост на **15–20 процентных пунктов** (в **2–2,33 раза**). **Это цель, не доказанный эффект.**
- **600 продаж/день** — количество заказов, а не число уникальных клиентов одной когорты. Без совпадающего знаменателя нельзя вывести «90 → 180–210 вернувшихся клиентов».
- **Предложенное определение:** доля клиентов, совершивших вторую оплаченную покупку в течение 60 дней после первой. Применимость исходных 15% к этому окну необходимо проверить.
- **RFM:** Champions, At Risk, Potential Loyalists, Hibernating. Индивидуальные действия, не общая скидочная рассылка.
- **Первый фокус:** помощь со второй покупкой для Potential Loyalists, затем проверка At Risk. В каждом сегменте — рандомизированный контроль.
- **Обязательная проверка:** повторные покупки по завершённым когортам, инкрементальная маржа, отписки и жалобы.

Исходный кейс не включает клиентские транзакции, поэтому доли сегментов и измеренный uplift **не выдуманы**. Достижение 30–35% не объявляется состоявшимся.
